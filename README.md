## Задача 1 — Перестановка букв слова

**Условие:** Пользователь вводит слово с клавиатуры. Программа случайным образом переставляет буквы этого слова до тех пор, пока перемешанное слово не совпадёт с исходным. После каждой перестановки слово выводится на экран, а в конце отображается общее количество попыток.

**Пример работы:**
```
Введите слово: корова
воакро
вокроа
ароовк
...
корова
9 попыток
```

**Реализация:**
- Используется `std::shuffle` для случайной перестановки символов строки.
- Генератор случайных чисел инициализируется через `std::mt19937`.
- Цикл `do...while` выполняется, пока перемешанное слово не станет равным исходному.
- Добавлена проверка на пустой ввод.

**Файлы:**

## Задача 2 — CalcTree9: Дерево арифметического выражения (инфиксная форма)

**Условие:** В текстовом файле `FN1` дано арифметическое выражение в инфиксной форме. Выражение может содержать операции `+`, `-`, `*`, `/`, `%`, `^`, целые числа из промежутка [1; 30] и переменную `x`. Необходимо:

1. Построить дерево выражения (операции одного приоритета вычисляются слева направо).
2. Вычислить значение выражения при заданном значении `x` и записать результат в файл `FN2`.
3. Преобразовать дерево: заменить все поддеревья вида `A + x` на `x + A`.
4. Вывести преобразованное дерево в файл `FN2` в префиксной, постфиксной и инфиксной (с избыточными скобками) формах.

**Реализация:**
- Инфиксное выражение преобразуется в постфиксную запись (алгоритм сортировочной станции).
- Из постфиксной записи строится бинарное дерево выражения.
- Рекурсивная функция `TransformAddCommute` обходит дерево и меняет местами операнды в узлах `+`, где правый потомок — переменная `x`.
- Реализованы функции вывода дерева в трёх формах записи.

**Файлы:**
- `head_Task2_DeepSeek.h` / `Task2_DeepSeek_functional.cpp` / `Task2_DeepSeek_main.cpp`
- `head_Task2_Gemini.h` / `Task2_Gemini_functional.cpp` / `Task2_Gemini_main.cpp`
- `head_Task2_Kimi.h` / `Task2_Kimi_functional.cpp` / `Task2_Kimi_main.cpp`

**Входные/выходные файлы:**
- Вход: `input.txt` — арифметическое выражение в инфиксной форме.
- Выход: `output.txt` — результат вычисления и представления дерева.

## Задача 3 — Graf2: Построение матрицы инцидентности

**Условие:** В текстовом файле `FileName1` задан неориентированный граф в виде матрицы смежности. Необходимо построить матрицу инцидентности и вывести её в файл `FileName2`.

Порядок нумерации рёбер: сначала рёбра, инцидентные вершине 1, затем вершине 2 и т.д. Рёбра одной вершины перечисляются по возрастанию номера смежной вершины. В первой строке выходного файла указывается размер матрицы (n × m), далее — сама матрица.

**Реализация:**
- Матрица смежности считывается из файла.
- Рёбра извлекаются обходом верхнего треугольника матрицы (i < j), что исключает дублирование.
- Для каждого ребра заполняются соответствующие позиции в матрице инцидентности.
- Добавлена валидация входных данных (проверка количества вершин, корректности значений матрицы).

**Файлы:**
- `head_Task3_DeepSeek.h` / `Task3_DeepSeek_functional.cpp` / `Task3_DeepSeek_main.cpp`
- `head_Task3_Gemini.h` / `Task3_Gemini_functional.cpp` / `Task3_Gemini_main.cpp`
- `head_Task3_Kimi.h` / `Task3_Kimi_functional.cpp` / `Task3_Kimi_main.cpp`

**Входные/выходные файлы:**
- Вход: `input2.txt` — количество вершин и матрица смежности.
- Выход: `output2.txt` — размер и матрица инцидентности.

## Код-стайл и внесённые исправления

При ревью кода, сгенерированного AI-ассистентами, были выявлены и исправлены следующие проблемы:

1. **`using namespace std;`** — закомментировано во всех файлах, где встречалось (Gemini, Kimi). Использование `using namespace std` в заголовочных файлах загрязняет глобальное пространство имён. Все вызовы стандартной библиотеки заменены на явные обращения через `std::`.

2. **Непонятные/короткие имена переменных** — переименованы в соответствии с конвенцией PascalCase (например: `rd` → `RandomDevice`, `g` → `Generator`, `seed` → `Seed`).

3. **Неявные преобразования типов** — добавлены явные приведения (`static_cast<unsigned int>(...)`) для устранения предупреждений компилятора.

4. **Комментарии** — весь код снабжён комментариями на русском языке, поясняющими логику работы основных блоков.

5. **Единый код-стайл:**
   - Открывающая фигурная скобка `{` на отдельной строке (стиль Allman).
   - Имена переменных и функций — `PascalCase`.
   - Параметры функций — с префиксом `In` / `Out` для обозначения направления данных.
   - Использование `#include` с явными заголовочными файлами без лишних включений.
